# Program Layanan Peserta Didik

## Dukungan untuk keberlanjutan belajar

Untuk menjaga keberlanjutan pendidikan, satuan pendidikan dapat memberikan subsidi kebutuhan belajar kepada murid yang memenuhi ketentuan. Bentuk dukungan dapat berupa pembebasan sebagian biaya kegiatan atau bantuan perlengkapan pembelajaran sesuai hasil penilaian.

## Tata cara

Peserta didik atau wali menyampaikan permohonan kepada petugas layanan. Tim melakukan pemeriksaan dokumen dan mencatat hasil penilaian sebelum menetapkan bentuk dukungan.

## Perlindungan informasi

Data pemohon dibatasi untuk petugas yang menangani layanan. Ringkasan untuk rapat hanya boleh menggunakan informasi agregat tanpa identitas pribadi.

## Evaluasi

Pelaksanaan program ditinjau setiap akhir semester untuk melihat ketepatan sasaran dan kesinambungan layanan.
